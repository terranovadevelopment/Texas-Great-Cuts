## Install
1. Extract this ZIP file.
2. Open the extracted folder and copy its **contents** (including `images/`) into your GitHub Desktop repository folder. The ZIP already has `index.html` at its root.
3. Replace existing files, then Commit to main and Push origin.
4. Wait for Render's latest deployment to show Live and refresh the website (Ctrl+F5).
